### 2. Deployment approach
Decision (user choice): **Render free tier for the FastAPI backend + Vercel for the Next.js frontend.**

Rationale: Vercel free tier cannot run a persistent uvicorn server; serverless functions are stateless (in-memory sessions and `probeiq.db` would not survive between turns).

Changes made:
- `frontend/next.config.js` — rewrite destination now reads `process.env.BACKEND_URL` (default `http://127.0.0.1:8000`), so local dev is unchanged.
- `render.yaml` — Render Blueprint (runtime python, free plan, branch fix-heuristics, start `uvicorn main:app --host 0.0.0.0 --port $PORT`).
- `DEPLOYMENT.md` — full step-by-step plan with env vars, caveats, and upgrade paths.
- `.python-version` — pin `3.12`.

## Known Free-Tier Caveats
- Render free web services sleep after 15 min idle → first request wakes it (~30–60 s cold start) and in-progress interviews are lost (404 on next turn).
- `probeiq.db` lives on ephemeral storage — history and reviewer decisions reset on backend restart.
- OpenRouter free quota may apply; app degrades to offline mock fallback rather than crashing.
